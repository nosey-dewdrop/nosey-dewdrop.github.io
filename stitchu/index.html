stitchu

a garment photo in, a real sewable A4 pattern out

by Damla Su Bilge · C++ / WASM / vision
open stitchu → C++ WASM computer vision

stitchu takes a photo of a garment, a few body measurements, and returns a real sewing pattern as a calibrated, print-ready A4 PDF you can cut against fabric. Not a picture of a pattern, the actual draft.

why a deterministic engine, not ML

The pattern is drafted by a C++ engine compiled to WASM, running on the reader's own processor. Every line comes from an explainable formula, not a model that guesses. This matters because a sewing pattern is cut against real cloth: if the same measurements produced a slightly different pattern next time, someone wastes money and fabric.

So the rule is same input, same pattern, every time. A rented model cannot promise that the way owned deterministic code can, and it costs 0 tokens per draft, whether one person opens it or a thousand do.

how it works

  • vision reads the garment photo and describes what it is (neckline, sleeve, silhouette)
  • a spec turns that reading into structured garment data
  • the C++ engine drafts the actual pattern pieces from the spec plus the measurements
  • the pieces are laid out flat and exported as a tiled, calibrated A4 PDF

measured, not claimed

stitchu keeps a public benchmark and a dated patch log. Every change to the engine is measured and published, the misses included, in the League-of-Legends patch-note tradition. The number the project tracks: how many of 54 real product photos become a complete, sewable pattern.

You can read the full, dated engineering log at stitchu.noseydewdrop.com/patches.html.

who built it

stitchu is built by Damla Su Bilge, one of 50+ projects and 20+ live products under noseydewdrop. It started as a Swift iOS app; the valuable core turned out to be the engine underneath, so the identity moved onto the C++ core and every platform became a thin consumer of the same draft.
